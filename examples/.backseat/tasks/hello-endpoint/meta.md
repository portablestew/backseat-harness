# Meta-prompt: hello-endpoint

Add a `GET /hello` endpoint to the existing web service that returns
`{"message": "hello"}` as JSON with a 200 status. Include a test that exercises
the endpoint through the app's normal test harness, and make sure the full test
suite passes.

Constraints:
- Match the project's existing framework, routing style, and test conventions.
- Do not add new dependencies.
- One small, verifiable step at a time.
